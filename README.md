# Preentrega M3 - RetailPro

## 📌 Descripción
Este proyecto corresponde a la **Preentrega M3** del curso de SQL en Coderhouse.  
Incluye la creación de una base de datos llamada **ventas_tech_db** con sus tablas, relaciones y datos de prueba.

---

## 📂 Archivos incluidos
- `ventas_tech_db.sql` → Script SQL con:
  - Creación de la base de datos
  - Definición de tablas (DDL)
  - Relaciones y constraints
  - Inserción de datos de prueba (DML)
- `README.md` → Documento con instrucciones de uso

---

## ⚙️ Instrucciones de ejecución
1. Abrir tu gestor de base de datos (MySQL Workbench, DBeaver, etc.).  
2. Crear una nueva conexión a tu servidor local.  
3. Ejecutar el script `ventas_tech_db.sql`.  
   - Esto generará la base de datos y cargará los datos iniciales.  
4. Verificar que las tablas se hayan creado correctamente.  
5. Realizar consultas de prueba sobre las tablas para validar la carga de datos.

---

## ✅ Objetivo del entregable
- Practicar la creación de bases de datos relacionales.  
- Aplicar **DDL** (Data Definition Language) y **DML** (Data Manipulation Language).  
- Documentar el proceso en un archivo `README.md` para asegurar reproducibilidad.
